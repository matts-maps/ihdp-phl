The Philippine Humanitarian Data Package is a catalogue of GIS layers covering the Philippines, built for disaster response, health, development, and climate resilience work. It brings together administrative boundaries, population statistics, OpenStreetMap/Geofabrik infrastructure and facility layers, and SRTM elevation data in one place, each with consistent metadata: source, licence, coordinate system, attributes, and use cases.

## Who it's for

National and local disaster response coordination bodies, health authorities, local government units, and humanitarian organisations working in the Philippines who need a starting point for GIS data rather than having to track down each source individually.

## What's in it

22 layers across six categories: boundaries, population, infrastructure, facilities, environment, and elevation. The full list is on the [homepage](/), with a detail page per layer covering its schema, licence, and how to get it.

## How data is hosted

GitHub doesn't accommodate large binary GIS files well, so this site hosts metadata and documentation, not the raw data itself. Each layer page links either to a hosted download (once uploaded) or to the original source (HDX, Geofabrik, USGS) in the meantime. See [Getting started](/guides/getting-started/) for the current state of each layer's availability.

## Licensing

Licensing is mixed and set per layer, since layers come from different sources under different terms (see each layer's page). Check the licence before redistributing or using a layer commercially.
