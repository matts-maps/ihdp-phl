## Overview

Agricultural land, farms, orchards, fishponds, and livestock facilities from OpenStreetMap.

| | |
|---|---|
| **Category** | environment |
| **Geometry type** | polygon |
| **Coordinate system** | EPSG:4326 |
| **Source** | OpenStreetMap / Geofabrik |
| **License** | ODbL 1.0 |
| **Attribution** | © OpenStreetMap contributors |
| **Last updated** | 2025-01-10 |
| **Feature count** | ~180,000 |
| **File size** | ~95 MB (GeoPackage) |

## Attributes

| Field | Type | Description |
|---|---|---|
| `osm_id` | string | OpenStreetMap ID |
| `name` | string | Farm/facility name |
| `landuse` | string | Agricultural type (farmland, orchards, grassland, etc.) |
| `crop` | string | Primary crop (if available) |

## Use cases

- Agricultural disaster impact assessment
- Food security planning
- Livelihood recovery in post-disaster phase
