## Overview

Building footprints for the Philippines extracted from OpenStreetMap by Geofabrik. Includes polygons representing residential, commercial, industrial, and other structures.

| | |
|---|---|
| **Category** | infrastructure |
| **Geometry type** | polygon |
| **Coordinate system** | EPSG:4326 |
| **Source** | OpenStreetMap / Geofabrik |
| **License** | ODbL 1.0 (OpenStreetMap License) |
| **Attribution** | © OpenStreetMap contributors |
| **Last updated** | 2025-01-10 |
| **Feature count** | ~8.5 million |
| **File size** | ~850 MB (GeoPackage) |

## Attributes

| Field | Type | Description |
|---|---|---|
| `osm_id` | string | OpenStreetMap ID |
| `name` | string | Building name (if available) |
| `building` | string | Building type (e.g., house, commercial, school) |
| `building_levels` | integer | Number of stories (if available) |
| `roof_material` | string | Roof type (if available) |

## Use cases

- Evacuation center identification
- Urban damage assessment post-disaster
- Population exposure analysis
