## Overview

Schools (primary, secondary, tertiary), universities, and educational institutions from OpenStreetMap.

| | |
|---|---|
| **Category** | facilities |
| **Geometry type** | point |
| **Coordinate system** | EPSG:4326 |
| **Source** | OpenStreetMap / Geofabrik |
| **License** | ODbL 1.0 |
| **Attribution** | © OpenStreetMap contributors |
| **Last updated** | 2025-01-10 |
| **Feature count** | ~32,000 |
| **File size** | ~20 MB (GeoPackage) |

## Attributes

| Field | Type | Description |
|---|---|---|
| `osm_id` | string | OpenStreetMap ID |
| `name` | string | School name |
| `amenity` | string | Facility type (school, university, college, etc.) |
| `operator` | string | School operator (public, private) |
| `phone` | string | Contact phone |

## Use cases

- Evacuation shelter identification
- Disaster preparedness drills planning
- Education sector vulnerability assessment
