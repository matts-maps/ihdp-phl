## Overview

Hospitals, clinics, health centers, pharmacies, and other healthcare facilities from OpenStreetMap for the Philippines.

| | |
|---|---|
| **Category** | facilities |
| **Geometry type** | point |
| **Coordinate system** | EPSG:4326 |
| **Source** | OpenStreetMap / Geofabrik |
| **License** | ODbL 1.0 |
| **Attribution** | © OpenStreetMap contributors |
| **Last updated** | 2025-01-10 |
| **Feature count** | ~18,500 |
| **File size** | ~15 MB (GeoPackage) |

## Attributes

| Field | Type | Description |
|---|---|---|
| `osm_id` | string | OpenStreetMap ID |
| `name` | string | Facility name |
| `healthcare` | string | Facility type (hospital, clinic, health_center, pharmacy, etc.) |
| `operator` | string | Operating organization |
| `phone` | string | Contact phone |
| `opening_hours` | string | Operating hours |

## Use cases

- Health emergency response planning
- Accessibility analysis for medical services
- Disease outbreak response coordination

## Notes

Urban hospitals well-mapped, rural health centers less complete. Cross-reference with official DOH registry for authoritative data.
