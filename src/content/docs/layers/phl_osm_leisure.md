## Overview

Parks, sports facilities, recreation areas, and tourist attractions from OpenStreetMap.

| | |
|---|---|
| **Category** | facilities |
| **Geometry type** | mixed |
| **Coordinate system** | EPSG:4326 |
| **Source** | OpenStreetMap / Geofabrik |
| **License** | ODbL 1.0 |
| **Attribution** | © OpenStreetMap contributors |
| **Last updated** | 2025-01-10 |
| **Feature count** | ~28,500 |
| **File size** | ~25 MB (GeoPackage) |

## Attributes

| Field | Type | Description |
|---|---|---|
| `osm_id` | string | OpenStreetMap ID |
| `name` | string | Facility name |
| `leisure` | string | Leisure type (park, sports_center, playground, garden, etc.) |
| `surface` | string | Surface type (grass, asphalt, etc.) |

## Use cases

- Open space identification for emergency shelters
- Community resilience assessment
- Urban planning
