## Overview

Military installations, government buildings, embassies, and administrative centers from OpenStreetMap.

| | |
|---|---|
| **Category** | infrastructure |
| **Geometry type** | mixed |
| **Coordinate system** | EPSG:4326 |
| **Source** | OpenStreetMap / Geofabrik |
| **License** | ODbL 1.0 |
| **Attribution** | © OpenStreetMap contributors |
| **Last updated** | 2025-01-10 |
| **Feature count** | ~3,500 |
| **File size** | ~6 MB (GeoPackage) |

## Attributes

| Field | Type | Description |
|---|---|---|
| `osm_id` | string | OpenStreetMap ID |
| `name` | string | Facility name |
| `military` | string | Military type (barracks, range, checkpoint, etc.) |
| `government` | string | Government facility type (administrative, embassy, etc.) |

## Use cases

- Disaster response coordination sites
- Government service accessibility
- Security and conflict mapping
