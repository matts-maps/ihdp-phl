## Overview

Natural features including forests, wetlands, grasslands, and protected areas mapped in OpenStreetMap.

| | |
|---|---|
| **Category** | environment |
| **Geometry type** | polygon |
| **Coordinate system** | EPSG:4326 |
| **Source** | OpenStreetMap / Geofabrik |
| **License** | ODbL 1.0 |
| **Attribution** | © OpenStreetMap contributors |
| **Last updated** | 2025-01-10 |
| **Feature count** | ~45,000 |
| **File size** | ~85 MB (GeoPackage) |

## Attributes

| Field | Type | Description |
|---|---|---|
| `osm_id` | string | OpenStreetMap ID |
| `name` | string | Natural area name |
| `natural` | string | Natural feature type (forest, wetland, grassland, scrub, etc.) |
| `protected_area` | string | Protected status (if applicable) |

## Use cases

- Biodiversity mapping
- Environmental conservation planning
- Watershed protection
