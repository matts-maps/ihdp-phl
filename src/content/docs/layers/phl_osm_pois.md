## Overview

Points of interest including hospitals, schools, police/fire stations, markets, religious sites, and other key facilities extracted from OpenStreetMap.

| | |
|---|---|
| **Category** | facilities |
| **Geometry type** | point |
| **Coordinate system** | EPSG:4326 |
| **Source** | OpenStreetMap / Geofabrik |
| **License** | ODbL 1.0 |
| **Attribution** | © OpenStreetMap contributors |
| **Last updated** | 2025-01-10 |
| **Feature count** | ~450,000 |
| **File size** | ~45 MB (GeoPackage) |

## Attributes

| Field | Type | Description |
|---|---|---|
| `osm_id` | string | OpenStreetMap ID |
| `name` | string | Facility name |
| `amenity` | string | Amenity type (hospital, school, police, fire_station, market, place_of_worship, etc.) |
| `operator` | string | Operating organization (if available) |
| `addr_street` | string | Street address |
| `phone` | string | Contact phone |
| `opening_hours` | string | Operating hours (if available) |

## Use cases

- Identifying emergency shelters and health facilities
- Humanitarian access assessment
- Service coverage mapping
