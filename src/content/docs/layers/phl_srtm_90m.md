## Overview

Shuttle Radar Topography Mission (SRTM) 90-meter resolution elevation data for the Philippines. Provides topographic information for the entire country.

## Attributes

| Field | Type | Description |
|---|---|---|
| `elevation` | float | Elevation in meters above sea level |

## Use cases

- Terrain analysis for disaster planning
- Slope calculation for landslide risk assessment
- Hydrological modeling and flood risk
- Accessibility and terrain-based routing

## Notes

Original SRTM data from 2000; post-processing and gap-filling have been applied. Vertical accuracy ±16m (90% confidence). Suitable for regional/national planning.
